# Паспорт проекта

## Название

**Консольная информационная система «Библиотека колледжа»**

## Цель

Учёт книг, журналов, читателей и выдач изданий в библиотеке колледжа.

## Пользователи

| Пользователь | Назначение |
|--------------|------------|
| Библиотекарь | Добавляет издания, регистрирует читателей, оформляет выдачу и возврат, сохраняет данные |
| Преподаватель | Ищет издания, просматривает список доступных изданий и активные выдачи |

## Ожидаемый результат

Консольная программа на C++, выполненная по единому техническому заданию и обеспечивающая:

- хранение коллекции изданий (книги и журналы), читателей и выдач;
- работу через консольное меню (команды 1–9 и 0 для выхода);
- сохранение и загрузку данных из файлов `items.txt`, `readers.txt`, `loans.txt`.

## Основные сущности

`LibraryItem` (абстрактный), `Book`, `Magazine`, `Reader`, `Loan`, `Library`.
