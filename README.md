Паспорт проекта

| Параметр                          | Содержание                                                                                                                                                                                                                        |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Название проекта**              | Консольная информационная система **«Библиотека колледжа»**                                                                                                                                                                       |
| **Цель проекта**                  | Учёт книг, журналов, читателей и выдач в библиотеке колледжа                                                                                                                                                                      |
| **Пользователи**                  | Библиотекарь, преподаватель                                                                                                                                                                                                       |
| **Результат проекта**             | Консольная программа на C++, реализующая техническое задание: классы `LibraryItem`, `Book`, `Magazine`, `Reader`, `Loan`, `Library`; меню 1–9 и 0; сохранение и загрузка данных из файлов `items.txt`, `readers.txt`, `loans.txt` |
| **Форма выполнения**              | Индивидуально или командой до 3 человек; техническое задание единое для всех                                                                                                                                                      |
| **Основные функции**              | 1 — добавить книгу; 2 — добавить журнал; 3 — зарегистрировать читателя; 4 — найти издание по `id`; 5 — выдать издание; 6 — вернуть издание; 7 — вывести доступные издания; 8 — вывести активные выдачи; 9 — сохранить; 0 — выход  |
| **Правила и ограничения**         | Уникальные `id` и `ticket`; `year` от 1500 до 2100; `month` от 1 до 12; нельзя выдать занятое издание, создать выдачу для отсутствующего читателя, вернуть уже возвращённое издание                                               |
| **Этапы практики**                | УП1 — постановка задачи; УП2 — требования и сценарии; УП3 — проектирование данных и классов; УП4 — каркас и меню; УП5 — функции проверки и модули                                                                                 |
| **Критерии готовности**           | Компилируемый проект; работающее меню; выполнение правил проверки; три контрольных сценария (успешная выдача, отказ повторной выдачи, успешный возврат); файловый ввод-вывод; комплект документации                               |
| **Срок представления результата** | По завершении этапов УП1–УП5 и реализации проекта в рамках учебной практики                                                                                                                                                       |

## Для запуска проекта запустить в консоли следующее: 
``` bash
./library
```
